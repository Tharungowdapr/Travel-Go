# Data Access Documentation

This document explains what data is stored in our databases and how to access it.

## 1. Supabase (Relational Data)
Supabase stores core business data including users, hotels, and bookings.

### Key Tables
- **`USER`**: Stores user profiles.
  - Columns: `UserID`, `UserName`, `FName`, `LName`, `Email`, `Password` (hashed), `Age`, `Gender`, `Address`.
- **`HOTEL`**: Stores hotel information.
  - Columns: `HotelID`, `HotelName`, `CityID`, `HotelRating`, `LodgingType`.
- **`BOOKING`**: Stores reservation details.
  - Columns: `BookingID`, `UserID`, `RoomTypeID`, `CheckinDate`, `CheckoutDate`, `NoOfRooms`, `Confirmed`.
- **`HOTEL_IMAGE`**: Stores URLs for hotel photos.
- **`ROOM_TYPE`**: Detailed room info (Price, Capacity).

### How to Access
- **Web UI**: Go to your [Supabase Dashboard](https://supabase.com/dashboard) and navigate to the **Table Editor**.
- **CLI/SQL**: Use the **SQL Editor** in the Supabase dashboard to run queries.
  ```sql
  -- Example: Insert a new country
  INSERT INTO "COUNTRY" ("CountryName") VALUES ('Germany');
  ```

### How to Add Data
There are three ways to add data to your online Supabase database:

1. **Automated (Recommended)**:
   Run the seeding script I've prepared in the backend. This will populate all tables with realistic sample data.
   ```bash
   cd backend
   node scripts/seedData.js
   ```

2. **SQL Editor**:
   Copy and run the contents of [schema.sql](file:///Users/tharungowdapr/Documents/college/5rth sem/dbms/TravelGo/backend/scripts/schema.sql) in your Supabase SQL Editor to create/reset tables, or run custom `INSERT` statements.

3. **Manual (Table Editor)**:
   Go to the **Table Editor** in the Supabase Dashboard, select a table (e.g., `HOTEL`), and click **Insert row**.

## 2. MongoDB (Non-Relational AI Data)
MongoDB is used for persistent storage of AI-related features.

### Key Collections
- **`ai_recommendations`**: Stores recommendations generated by Gemini for users.
  - Fields: `userId`, `hotelName`, `recommendationText`, `timestamp`.
- **`search_history`**: (Planned) User search patterns for better AI context.

### How to Access
- **MongoDB Atlas**: Log in to your Atlas cluster, go to **Database**, and click **Browse Collections**.
- **Compass**: Use MongoDB Compass (Desktop Client) with the connection string from your `.env` file (`MONGODB_URI`).

## ⚠️ Important Notes
- **Authentication**: User authentication is handled via Supabase, but sessions are managed in the backend using JWT.
- **Environment Variables**: Credentials for these services are located in the `.env` files of both `backend/` and `my_react_app/` (v2/frontend).
